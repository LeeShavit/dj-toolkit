# Version matching

Most "wrong downloads" are the right song in the wrong version. The rules below come from real runs.

## Naming vocabulary
- **Extended Mix / Extended Version / Extended**: the DJ version with intro and outro beats. Usually 1-3 minutes longer than the radio edit.
- **Club Mix / Original Mix**: on Beatport, "Original Mix" usually *is* the full-length club version, not the radio edit.
- **Radio Edit / Edit / Short Edit**: the short version. Not wanted when the preference is extended.
- **"<Name> Remix"** is a different track from the original, and **"<Name> Extended Remix"** is that remix's long version. Don't swap remixers: a "Hardwell & Maddix Remix" is not "Original Extended".
- **"Dub"** and **"Instrumental"** have no vocals. Only accept them if asked for.
- **"Remastered" / "2024 Version" / "Re-Edit" / "VIP" / "Rework"** are distinct releases. Match them when they're named.

## Matching a downloaded file
Accept when:
- the artist and title match (ignore case, accents, `feat.`, `&` vs `,` vs `x`, and artist order), and
- the version words match the target, or the source's metadata proves it (e.g. a Beatport track ID), and
- the length is plausible: extended ≥ radio length + ~45 s. If you know the official length (Beatport lists it), stay within ±5 s.

Reject or flag:
- a different remixer's name in the filename
- "edit", "radio", "short" when extended was the target
- an extended version under ~3:30 for dance music
- a FLAC under ~500 kbps average (likely a transcode), or an MP3 claiming 320 with a duration or size mismatch

## Searching tips
- Beatport and Traxsource titles are the best way to learn which versions exist and how long they are.
- Many tools match better without brackets: search "Artist Title" first, then filter by version words.
- Collaborations: try the main artist alone if the full artist string finds nothing.
